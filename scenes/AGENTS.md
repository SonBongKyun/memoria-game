# MEMORIA Scene Agent Rules

These instructions apply to changes under `scenes/`.

Read `../docs/CANON_V2_STABILIZATION.md` before changing story flow or the public demo route.

## Current objective

Polish the first public vertical slice. Do not expand map count or chapter count by default.

The demo should prove:

1. the player understands Memory Burn,
2. the player cares about at least one memory before sacrificing it,
3. a later scene visibly changes because of that sacrifice,
4. Elia feels like a person rather than a tutorial anchor,
5. the demo ends with curiosity about BL-07 / Authority pressure.

## Preferred route

Rim Forest → first meaningful burn → Elia bond → Verdan context → second costly temptation → World Rewrite callback → Authority/Kairos pressure → BL-07 tease.

## Scene design rule

When choosing between a new scene and strengthening a callback in an existing scene, strengthen the callback.

Avoid long low-agency exposition. Prefer the player discovering the cost of memory loss through changed behavior, missing interactions, altered visuals, or absent dialogue.

## Canon

Current narrative authority is Master Bible v9.0 + completed manuscript. Older GDD material is historical reference if it conflicts with current canon.

Do not expose legacy memory-grade numbering as narrative truth.

## Validation

Scene changes must preserve:

- save/load destinations
- checkpoint safety
- memory-dependent variants
- controller navigation
- Korean/English text layout
- demo pacing
