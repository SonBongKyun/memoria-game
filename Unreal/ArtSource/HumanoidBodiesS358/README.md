# S358 humanoid silhouettes and NPC tailoring

Thirteen immutable meshes reuse the original paint, material packages, 77-bone rigs and all animation clips. Nine ambient NPCs gain tailored cuffs, boot shafts/bindings, rolled lapels, fasteners and role-specific tabards/shoulder bindings. Elia and Malet gain rear accessory piping while retaining their complete painted costumes. Two foe families replace their slot-0 torso/arm/leg primitives with fitted waistcoats, articulated sleeves/trousers, layered shoulders, bracers, boots, split overcoats and belts. Original articulated hands/feet, gear slot and the complete S357 face/neck slot survive unchanged.

Run Blender 4.5 background with `Unreal/Tools/build_humanoid_bodies_s358.py`. Each output directory is refused when present. No raster image generation or pixel editing is used; original atlas/paint/materials are reused. Geometry receipts record exact source/output/generator hashes, retained corner digests and unchanged bind matrices. Original retained split normals are restored after joining. NPC FBX colors export SRGB to match existing paint pipeline; foes use LINEAR categorical colors to match S357 materials.

Import only new targets using `-run=MemoriaHumanoidS358 -AllowCommandletRendering -RenderOffscreen`. Legacy FBX import uses the original skeleton, fixed axes and no animation/texture/material/physics generation. Exactly 13 new skeletal packages are created under `/Game/Memoria/Presentation/Field3D/HumanoidBodiesS358/R3/`. All prior packages are immutable. Changed FBX needs an explicit fresh revision or disposable scratch copy, never in-place reimport. Native views and runtime pose checks are required for acceptance. Final review/results are in `docs/unreal-migration/S358_REVIEW.md` and `S358_RESULTS.json`.

## Native neck correction

R2 passed all 37 automated checks, but native close views revealed an inherited S354 rigid-neck and chest-weighted collar connection stretching into strips on the nine ambient NPCs. R3 replaces only the 32-vertex neck cylinder and 48-vertex upper collar ring with a continuous neck blended between the actual neck and head bones and a raised collar. Remaining body and painted head/hair geometry, UVs, weights and split normals remain intact. Explicit removal counts and retained-corner digests are recorded. Source and provisional packages for R1/R2 remain under Saved validation archives and are excluded from accepted game content.
