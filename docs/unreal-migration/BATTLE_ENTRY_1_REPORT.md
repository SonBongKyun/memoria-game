# S291 — 베르단 재방문·전투 진입·도주와 임시 전투 아트

상태: S291 전투 진입·도주 작업 완료. 최종 UE5.8.2 빌드 및 관련 렌더 검증99/99 통과. 전체 전투·15~20분 통합 구간은 후속 작업입니다.

## 플레이 범위

- 상점 종료 직후 저장 → Load checkpoint → Return to Verdan으로 실제 맵 재입장.
- 원본처럼 완료된 베르단에 재입장했을 때만 보행 인카운터가 활성화됩니다. 최초 방문이나 저장 화면 자체에서는 활성화되지 않습니다.
- 원본 32픽셀 타일 기준 60~100보, 72% 경고, Alley Rat / Market Thief 선택 순서를 유지합니다. 시간당 확률로 대체하지 않았습니다.
- 전투 시작의 체력 성장·포커스 소비·전투 수/최고 공명 단계·도입 선택의 잔향·목표·연소 이력에 따른 수정자를 반영합니다. 일반 난이도/NG0/현재 미장착 장비 범위입니다.
- 이번 명령은 도주만 지원합니다. 원본 일반 인카운터의 확정 도주와 0.3초 정리 후 실제 베르단 재입장을 연결했습니다. 도주 뒤 위치는 원본 기본 위치 (128,288)입니다. 전리품·기억·잔액을 추가하지 않으며 체크포인트도 덮어쓰지 않습니다.
- 공격·방어·적 턴·전투 기억 연소·승패/보상·동행 기술·전체 BattleManager 이식은 미완료입니다. 전투 시작의 엘리아 쿨다운 초기화는 아직 없는 일지 도메인에 적용했다고 주장하지 않고 요청 관찰로 구분합니다.
- Chapter3 이동·업적 영구 저장·사람이 측정한 15~20분 통합 플레이 완성은 이번 결과가 아닙니다.

## 화면과 원고 경계

원본 시장·아렐·엘리아 그림을 잉크색 패널과 얇은 황동색 선으로 구성했습니다. 그림 비율을 유지하고 HP만 막대로 표시합니다. 원본 Alley Rat의 하운드 아트 매핑도 잠정 레거시 표현입니다.

Market Thief의 기존 128px 절차적 스프라이트를 원본 함수의 격리 실행으로 추출·보존했습니다. 추가 그림은 `Unreal/ArtSource/BattleEntry/market_thief_study_v1.png`의 **미승인 임시 시안**입니다. 빌트인 image_gen으로 제작했으며 프롬프트·해시·참고 링크는 같은 폴더의 provenance JSON에 있습니다. 원본 그림이나 적 데이터는 바꾸지 않습니다.

Notion 자료는 로컬에서 읽기 전용으로 검토했습니다. 미승인 원고의 분위기만 아트 참고로 사용하고 게임 구현과 설정 확정은 구분합니다.

## 검증과 증거

- 원본 실제 실행46와 독립 재현46 통과. 3개 비중립 접근은 source-only 비교 자료이며 네이티브 지원으로 주장하지 않습니다.
- 네이티브 대상47 = 원본 일반 진입43 + 거리/수명/저장3 + 실제 렌더 재방문1.
- 첫 렌더는 실제 재방문/도주 흐름과 거리/수명/저장4개 통과, 원본 비교43개 실패. 원인은 도주 시 presence 요청 및 도입 선택 플래그 알림 누락이었고 게임 수치 차이와 구분해 수정했습니다.
- 첫 RNG 증거 직렬화의 정수 전용 canonical helper 문제를 수정했습니다. 소수 RNG는 종류·범위·값·순서를 직접 비교하고 원시 JSON은 일반 직렬화로 저장합니다. 비교 조건을 완화하지 않았습니다.
- 첫 컴파일의 긴 문자열 C2026, 전체 PixelSprite 격리 시 미사용 의존성 파싱 실패, NullRHI 텍스처 크기 검사 실패를 보존했습니다. 문자열 분할/정확한 함수 의존 범위/저장 원본 크기 검사로 해결했습니다.
- 빌드와 새 초상1개 가져오기 및 전체 텍스처6개 별도 프로세스 재읽기 통과. 기존 5개 새 패키지를 덮어쓰지 않았습니다.
- 최종 렌더 **99/99 PASS**: BattleEntry47, 회귀49(서고10/시각3/체크포인트6/거래14/상점12/도입부4), 별도 프로세스 Continue3. 세 실행의 최종 native 소스가 현재 파일과 바이트 단위로 일치합니다.
- 최종 Host114/static76 PASS. 전체 Memoria280·배포 패키징·성능·사람의15~20분 플레이는 미실행입니다.
- 엔진 PreInit smoke `Condition failed`15건은 각 실행에 남고 이전 S289/S290에도 있습니다. 구체 원인·무해 여부는 미확정이며 선택 검사99 PASS와 구분해 `engine_startup_diagnostics.json`에 보존했습니다.
- 정확한 검사 ID·실행 ZIP 해시는 `validated_coverage.json`, 최종 원본·worktree·패키지 보존은 `preservation_final.json`에 기록합니다.

모든 원시 실행 증거와 코드·로그·캡처는 로컬 [evidence/battle1](evidence/battle1)에 보존했습니다. 공개 브랜치에는 검증 요약과 대표 화면만 포함합니다. 진입 기준22599개 해시와 이전 Source/Tools/문서 ZIP을 보관했습니다. 최종 보존 검사 PASS: 원본4217·이전UE95·보호 worktree22579·과거 증거/fixture·HEAD 동일, 새 텍스처6개만 추가했습니다. commit/push/배포는 하지 않습니다.
