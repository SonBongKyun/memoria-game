# Asset inventory and transfer plan

Snapshot: 2026-09-06. Original files remain untouched. [assets.csv](evidence/assets.csv) enumerates **every file under `assets/` and `mugic/`**, with path, byte size, PNG dimensions, migration classification, and literal-reference evidence. JPEG dimensions were not decoded by this scanner. A missing literal reference is not proof that an asset is unused: galleries, generated names, directories and dynamic lookup tables are common. No deletion is recommended from this scan.

## Reproducible asset importer design

Create a role manifest with stable asset ID, original path/hash, source dimensions, region/pivot, alpha/filter mode, sRGB, target package, dependencies, generated-artifact settings and provenance. Use hashed source lookup/cache outside Unreal Content for conversion intermediates; store only needed cooked assets in the project. Preserve case and Unicode normalization consistently on Windows and CI.

Separate presets for painterly CG, UI/portraits, pixel/procedural sprites, masks and stage textures. Source `project.godot` defaults to nearest filtering but several generated/real-art components override to linear; a single global “pixel art” import preset would be wrong. Validate sampler/filter overrides at use sites. Soft-load chapter CG and gallery thumbnails to avoid loading the entire 1.09 GB source CG collection on startup.

Import dependency validation must include portrait maps, gallery manifests, map-constructed asset names, VFX shader paths and procedural-generation fallbacks. Maintain a source-to-package report and measure loaded/cooked size separately from original byte size. Old 150–300 MB build guidance does not describe the current 1.19 GB Godot validation pack.

No new licensing conclusion follows from a file's presence. Existing font/art README notes are useful but not a complete commercial asset register. Before public UE distribution, attach original generation/download/licensing evidence for shipped art/music/fonts and any borrowed shader implementation. This does not block local Phase 0 design.
