# Test-only narrative IR

Generated by `Unreal/Tools/narrative_test_fixtures.py`. These are isolated
contract fixtures, never campaign content and never production import input.
Their provenance is inherited solely to test the bounded validator and typed
contracts; the synthetic payload intentionally differs from that source.

`synthetic_*` exercises inspected source branches absent from the selected
story group. `reject_*` tests strict validation failures. `modified_semantic`
changes one text payload and recomputes its semantic fingerprint. Unreal tests
copy that last IR into Saved/Validation, create only transient objects, and
prove production source attestation rejects the change. No temporary `.uasset`
is saved. The importer rejects these fixtures when source verification is on.

Original narrative values in generated test copies are derived from extraction,
not independently hand-maintained. `--check` verifies generation without writing.
