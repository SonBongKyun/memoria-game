## 버전과 의미 충돌

- 구 GDD의 설계 중심은 기억을 자원·이야기·정체성으로 다루고, 선택의 대가를 관계와 세계에 남기는 것이다. 픽셀 탐험·중요 장면 삽화·기억 서고라는 방향은 참고할 수 있으나 옛 엔진·수치·챕터 구성을 현재 Unreal 명세로 복사하지 않는다.
- GDD의 기억 Grade는 5에서 1로 갈수록 강해지는 구성이며, Bible의 연소등급은 1에서 5로 커진다. 서로 다른 분류를 같은 척도로 합치거나 원본 게임 데이터의 숫자를 자동 반전하지 않는다.
- GDD의 잔여 기록량 막대 예시는 현재 프로젝트의 **누적소실률 게이지 금지**와 충돌하므로 채택하지 않는다. 개별 기억 상태와 원본에 존재하는 반응을 사용한다.
- RW_CONTROL은 선행 승인·병행판 폐기·게임 동기화를 추정하지 말라고 명시한다. Ch18까지 새 페이지가 저장되었다는 사실은 재집필 승인이나 게임 반영 완료를 뜻하지 않는다.
- Ch02 인계에서 첫 검 기억 거래는 **추출되어 타인 소유가 된 것**이다. 추가 연소가 아니며, 추출 뒤 내용을 회상하지 못하지만 앰플의 기억 자체가 파괴되었다고 확정하지 않는다. 이후 재주입·복원도 미정이다. 이는 현재 Godot 거래 이식 경로가 실행·관찰하는 연소 기반 의미와 충돌하므로 **암묵적으로 메카닉을 전환하지 않는다**. 실행 원본은 현재 이식 동작의 근거이고, 재집필 초안은 문학적 검토 자료다. 어느 쪽도 이 비교만으로 최종 소설 설정이나 통합 게임 설계로 확정하지 않는다.
- 말레트/말레/마레트, 더 썸/더 섬프, 인접 회차의 방향·지도 차이는 별도 미결이다. 이번 문서와 시각 작업으로 통일하지 않는다.

## S291 시각 작업에 적용한 범위

Ch02에는 수레로 좁아진 길, 기름과 연기, 젖은 골목, 벗겨진 간판, 지하 등불과 호박색 앰플이 나온다. S291은 이 중 **젖은 골목과 따뜻한 호박색 조명이라는 분위기만 임시 아트 참고**로 사용한다. 구체적인 인물 신원·종족·설정·사건을 추가 확정하는 근거로 쓰지 않는다.

새 이미지 `Unreal/ArtSource/BattleEntry/market_thief_study_v1.png`는 built-in image_gen으로 만든 별도 시각 연구다. 같은 위치의 `market_thief_study_v1.provenance.json`은 `PROVISIONAL_VISUAL_STUDY_NOT_APPROVED_CANON`, `replaces_original: false`, `gameplay_effects: false`를 기록한다. 기존 원본 절차 생성 대체 스프라이트는 보존한다. 새 이미지의 인물 비례와 의상은 최종 캐릭터 디자인·신원·종족 설정이 아니다.

S291의 실제 기능 범위는 베르단 재진입→조우→첫 플레이어 턴 표시→도주→필드 복귀다. 공격·방어·연소·승패 전체가 완성되었다고 표시하지 않는다. 다음 전투 작업은 원본 메서드를 실행한 계약 검증을 먼저 확보하고, 기억 선택과 결과를 읽을 수 있게 표현한다. 이 문서는 새 전투 규칙을 승인하지 않는다.

Notion 쓰기, 기존 소설·원본 Game 변경, 원격 push는 수행하지 않았다.
