### 실행 중 발견하고 고친 문제

- 긴 Windows 경로에서 임시 파일은 써졌지만 원자적 이름 변경이 실패했다. 실제 282자 경로 API 재현에서 원래 경로는 오류 3, 정규화된 확장 경로는 성공했다. 동일한 `MoveFileExW` no-replace/교체·write-through 계약과 백업·임시 검증을 유지한 채 드라이브·UNC 경로를 정규화하고, 실제 긴 경로 I/O 회귀를 추가했다. 시스템 레지스트리는 바꾸지 않았다.
- 문자열/FName으로 이동하는 베르단 호스트가 쿠킹에서 빠졌다. 실제 이동한 네 지도만 `MapsToCook`에 명시하고 IoStore 본문 목록과 런타임 이동을 확인했다.
- 설치된 UE 5.8의 비차단 CSV Stop 재시도가 완료된 writer를 다시 종료하는 경쟁 상태를 실제 로그·엔진 소스에서 확인했다. 엔진 기본값인 `csv.BlockOnCaptureEnd 1`로 종료하고 완료 Future·최종 헤더·파일 해시와 외부 600초 종료 제한을 유지한다. 종료 단계는 성능 표본에서 제외한다.
- 최종 읽기 검토에서 타이틀→베르단 복원 뒤 `bTitle`이 남아 타이틀이 다시 나타나는 경로를 찾았다. 성공한 복원 뒤에만 이를 해제하고 실제 타이틀 수동/자동 두 경로의 회귀를 추가했다. 앞선 드리프트 타이틀 검사는 지역 진입 자체가 플래그를 지워 이 문제를 검출하지 못했다.
