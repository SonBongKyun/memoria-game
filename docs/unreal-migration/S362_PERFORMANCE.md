### 후속 작업 예산과 한계

후속 대표 플레이 측정의 임시 목표는 1280×720 / DX11 / 60FPS, 프레임 p95≤16.67ms다. 보조 경보선은 GPU p95≤12ms, 게임·렌더 각≤8ms, RHI≤4ms, DXGI 프로세스 사용이 가변 예산의 80% 미만인 상태다. 이번 짧은 실행에 소급 적용한 합격 기준이나 게임 설정 변경이 아니다.

현재 수치만으로 LOD·텍스처 스트리밍·이펙트 배칭을 일괄 바꾸지 않았다. 대표 전투·지역 왕복의 스파이크를 트레이스로 확인한 뒤 원인이 확인된 범위를 고친다. 워밍업·고정 길이 대표 벤치마크·사람의 전 구간 플레이·저사양·장시간·Shipping 성능·이전 버전 대비 개선을 주장하지 않는다. 별도 에디터의 8종 외형 검사도 이 패키지의 게임 성능과 합치지 않았다. CSV 종료는 엔진 기본 차단 모드로 완료하며 외부 프로세스 제한을 유지한다.
