# Starting-memory IR v1

`starting_memory_catalog.v1.json` is generated from executable Godot source, never edited by hand. `starting_memory_oracle.v1.json` is separate test evidence: initial connections/state and representative command/event observations from the unchanged Godot oracle. Mutable state and derived connections never enter the catalog definitions.

The root contains `schema_version`, `content_kind`, `extractor_version`, `source_repository_revision`, ordered `sources`, ordered `entries`, and `semantic_sha256`. Each entry has exact `id`, `title`, `description`, raw `grade` (0-4), positive integer `burn_power`, `story_effect`, `related_npc`, and `localization_ko`. Korean rows contain title, description and nullable story effect; null preserves absence of an authored effect override. IDs and text are not trimmed or normalized. English fields remain the existing definition fields; localization is typed catalog data separate from SaveGame schema 1.

Canonical bytes: UTF-8, no BOM, literal Unicode, lexicographically sorted ASCII object keys, compact separators, one trailing LF. Entry arrays retain source insertion order. Integers use decimal syntax; no floats, NaN or numeric strings in catalog content. JSON duplicates, unknown fields and noncanonical bytes are rejected. New IR JSON has an explicit LF Git attribute. Source SHA-256 uses UTF-8/LF normalized in memory so Windows CRLF checkout behavior cannot change content identity; raw source-byte hashes stay in diagnostic evidence.

The semantic SHA-256 covers canonical `{content_kind, entries, schema_version}` bytes, including entry order and Korean field presence. Full IR SHA-256 also covers provenance. Typed Unreal asset semantics are reconstructed independently into this same canonical payload by editor-only C++. Reimport compares every reflected catalog field as well as the semantic fingerprint; identical content and provenance return UNCHANGED without saving. Package binary equality is supplemental evidence, not the portable determinism contract.

Use `export_starting_memory.py --godot <4.6.2-console>` to deliberately generate a reviewed content revision. Use `--check` for validation: it executes source into temporary storage and compares both committed artifacts, with no regeneration. `import_starting_memory.py --engine-root <UE5.8.2> --godot <4.6.2-console> --build --evidence-dir <fresh-directory>` performs the source check and imports twice plus reloads in a third UE process. See [Phase 1C report](../PHASE_1C_REPORT.md) for exact paths, source hashes, commands and acceptance evidence.
