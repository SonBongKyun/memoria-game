## 2. 화별 상세 브리프

### 21화 「다시 베르단」 (`MEMORIA_KR_Ch021_final.md`)

#### 순서별 비트 (1비트 = 1행 + 원고 핵심 인용)
1. **양 우리 출발·남쪽 길 (3~21행):** 엘리아가 세이블의 손을 자기 왼팔에 걸어 인도하며 마른 시내를 따라 남쪽으로 이동 — `"도시까지 얼마나 걸려요." / "네 시간."` (7~9행)
2. **두 번째 신호탑 (23~33행):** 어제와 달리 깃발이 **기둥 꼭대기**까지 올라가 있고 흙길이 단단해 부츠 뒤꿈치가 쓸림 — `"이번엔 위에 있어요. 깃발이."` (27~31행)
3. **베르단 앞 비탈·세이블과 작별 (35~127행):** 기름에 매운 것을 볶는 냄새와 성벽 없는 노점들이 드러나자 세이블이 멈춰 서쪽으로 간 사람들을 찾으러 북쪽으로 되돌아가며 두 가지 당부 — `"나는 여기까지다."` (45행) / `"어제 창구에 있던 자 하나한테 네 화를 다 쓰지 마. 도시에는 그런 자가 많아."` (81행) / `"이 아이가 들던 걸 놓치면, 먼저 받아 줘라. 왜 놓쳤는지 묻느라 늦지 말고."` (89행) / `"갈림에서 길 잘 물어."` (109행)
4. **텅 빈 베르단 시장·공동 저수지 (131~157행):** 노점들이 짐을 싸고 의자 다리가 삐져나온 수레가 도시 밖으로 빠져나감; 전에 묵었던 헛간 옆 공동 저수지에서 물통만 채움 — `"전에는 이 시간에도 시끄러웠어."` (139행)
5. **봉인된 셈터 (159~205행):** 무두장과 닫힌 약방 사이 `셈터` 간판 아래 돌계단 세 층을 내려가니, 나무 문이 끈과 **관리국의 붉은 밀랍 인장**으로 봉인되어 있고 안은 적막함 — `"닫혔어."` / `"말레트."` (175~181행)
6. **동쪽 모퉁이 기름 노점 상인 (209~277행):** 구부린 철사로 채소를 건지는 상인에게 말레트의 행방을 묻자 사나흘 전 잡혀갔다고 암시 — `"밑으로 갔어."` / `"파일됐어."` (229~235행) / `"남의 기록은 펼쳐도 자기 기록은 안 보여 주는 놈."` / `"에디터."` / `"에디터라고 한 적 없어. 이름도 안 했어."` (257~267행)
7. **골목 대화·장부 우려 (279~367행):** 말레트의 장부가 넘어갔을지 모른다는 엘리아의 불안; 엘리아는 코트 속 책을 여기서 꺼내거나 확인하기를 거부하고 도시를 나가자고 함 — `"그 사람 장부까지 가져갔으면. 네가 뭘 팔았는지도 있을 거야. 지도를 받은 것도."` (299~305행) / `"여기서 확인하고 싶지 않아."` (337행)
8. **베르단 동쪽 이탈·묵은 밭 고랑 야영 (371~415행):** 들어온 길과 다른 골목으로 빠져 동쪽 밭으로 나감; 해 질 녘 두 고랑이 만나는 움푹한 자리에 앉아 왼손으로 검띠를 풀고 남은 빵을 나눔 — `"물통을 먼저 건넬 사람이 하나 줄었다."` (413행)
9. **밤·백 노트의 첫 방향 공명 (419~519행):** 엘리아가 **표지를 열지 않은 채** 왼손바닥(굽은 흉터)을 올려두자 책이 따뜻해지며 **북서쪽**으로 기운다고 느낌 — `"따뜻해졌어."` / `"기울고 있어."` (429~437행) / `"이 책 같은 게 있어."` (475행) / `"이건 확실해. 북서쪽."` (497행) / `"밝아지면 가 보자."` (501행)

### 22화 「공명」 (`MEMORIA_KR_Ch022_final.md`)

#### 순서별 비트 (1비트 = 1행 + 원고 핵심 인용)
1. **고랑의 아침 (3~41행):** 밤새 거의 못 잔 아렐이 왼손으로 검띠를 매고, 엘리아가 닫힌 표지 위에 왼손을 대어 **북서쪽** 방향을 재확인한 뒤 목초지로 출발 — `"북서쪽."` (15행) / `"많이는 못 잤어." / "그건 보이네."` (31~33행)
2. **돌담 밭과 더 선명해지는 감각 (45~70행):** 괭이질하는 농부(고개 안 듦)를 지나 밭 가장자리로 우회; 엘리아가 코트 위로 책을 짚으며 가까워졌음을 확인 — `"더 잘 느껴져." / "가까워졌다는 거야?" / "그런 것 같아."` (55~59행)
3. **서쪽 신호탑 우회·그루터기 숲 (71~107행):** 서쪽 길가에 반기(중간) 걸린 신호탑과 수레 짐 내리는 사람이 보이자, 무너진 북쪽 돌담을 넘어 베어 낸 나무 그루터기 지대로 우회(아렐 오른손에서 가방 끈이 미끄러져 왼팔로 받침) — `"저길 지나야 해?" / "길로 가면."` (81~83행)
4. **그루터기 휴식·아렐의 깜빡 잠 (111~147행):** 젖은 부츠 뒤축 천을 고치려다 오른손에서 끈이 빠져 잠시 기댔는데 그대로 잠듦; 깨어 보니 엘리아가 길을 지키며 빵을 남겨 두었음 — `"얼마나 지났어?" / "빵 먹고도 한참."` (127~129행)
5. **능선 아래 지붕 없는 농가 발견 (151~170행):** 높은 벽 셋 + 무너진 모서리 하나, 열린 쪽 앞으로 능선에서 내려오는 좁은 길; 빗물에 휜 선반과 깨진 그릇 — `"오늘은 여기서 자자."` (165행)
6. **책을 열 것인가 다툼 (171~247행):** 거리가 가늠되지 않아 엘리아가 책을 열고 싶어 하지만, 아렐이 길 위의 사내(12화) 때를 짚으며 멈춰 세움 — `"열면 더 알 수 있을 것 같아."` (199행) / `"덮고 싶을 때 덮을 수 있어?"` (221행) / `"지금은 내 손이야." / "그때도 네 손이었어."` (225~227행) / `"안 열 거야. ...지금은."` (239~243행)
7. **불 없는 밤·만지지 않았는데 가까워지는 온기 (251~347행):** 능선에서 내려다보여 불을 피우지 않음; 엘리아가 **손을 대지도 않았는데** 코트 아래 책이 더 따뜻해지고 가까워짐을 느낌(우리는 멈춰 있는데 상대가 움직이고 있음!) → 떨어뜨릴까 봐 닫힌 책을 가방 안에 넣음 — `"안 만지고 있었어... 그런데 더 가까워진 것 같아."` (277~285행) / `"우리는 안 움직였잖아... 그쪽이 오는 걸까."` (289~293행) / `"책이 깨어 있는 것 같아."` (307행) / `"손이 멈추는 건 볼 수 있어."` (335행)
8. **북서쪽 구름 아래 빛·불침번 (351~369행):** 어둠이 익은 뒤 능선 너머 북서쪽 구름 아래에 고정된 빛(마을/도시 불빛)이 보임; 아렐은 찬 기운이 도는 오른손 손가락을 천천히 편 뒤 **검을 왼손 가까이** 당겨 놓고 농가로 내려오는 길을 감시하며 22화 종료 — `"구름 아래의 빛은 계속 남아 있었다. 아렐은 그 빛보다 낮은 곳, 농가로 내려오는 길을 보고 있었다."` (369행)
