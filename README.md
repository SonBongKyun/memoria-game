# MEMORIA: The Price of Oblivion

Dark-fantasy 2D narrative RPG built with Godot 4.6.x and GDScript.

> **Canon notice:** the public `main` branch currently trails the latest local Season 1 rebuild. Read [`docs/CANON_STATUS.md`](docs/CANON_STATUS.md) before making story, dialogue, progression, or Memory-system changes.

## Current development direction

- Season 1 canon: 46 chapters
- Engine: Godot 4.6.2
- Core gameplay: exploration, turn-based battle, memory burning, persistent Memory/Knowledge consequences
- Current canonical rebuild checkpoint: through Chapter 5 (`The Classifier`), with Chapter 6 as the next gameplay migration after the current writing pause

## Repository guidance

- `AGENTS.md` / `CLAUDE.md`: development-agent instructions; some legacy sections on `main` still need canon sync
- `SESSION_LOG.md`: historical development log
- `docs/CANON_STATUS.md`: temporary canon guardrail while the canonical rebuild is being synchronized
- `BUILD_GUIDE.md`: legacy demo build guidance; verify scope/version before using
- `STEAM_PAGE.md`: legacy pre-rebuild store-page draft; do not treat its old ending count/playtime as current canon

## Before contributing

Do not resurrect legacy story assumptions solely because they still exist in old runtime code or documentation. In particular, early Tobias progression, Sable's old Cleaner material, the 12-person memorial, the old Malet→Sable ripple, and the old multi-ending Name Burn structure are superseded by the latest Season 1 canon.

Repository-sync work is tracked in GitHub issue #2.
